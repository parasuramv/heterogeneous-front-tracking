# Notebooks

Start with **[02 · Ready-to-run examples](02_ready_to_run_examples.ipynb)**: run
every cell. Then use **[01 · Playground](01_playground.ipynb)** for your own $g$,
level spacing δ, power $p$ in $h(u)=|u|^p$, mesh, initial data and window, on the line or on the circle.

01 and 02 bundle a readable snapshot of `src/hetfront` (a collapsed cell), so a
downloaded copy runs in any Jupyter. Inside a checkout they use `src/` instead.

The theory series (03–08) requires the repository and its installed dependencies:

| | |
| --- | --- |
| 03 | stationary profiles, the θ Riemann rule, δ-fans versus characteristics |
| 04 | straightening variables σ = √\|g_Δ\|, closed form versus RK4, passive corners, general powers \|u\|^p |
| 05 | the event loop, Theorem 2.4 invariants, cost, agreement with `fronttrack` |
| 06 | zeros of g: absorption, blow-up, non-uniqueness, the selected solution |
| 07 | empirical convergence in δ and Δ, selectable power, recorded general-power comparisons |
| 08 | the circle: wraparound, homogenisation, sign arcs through the seam |

## Run locally

```bash
python -m pip install -e ".[notebook]"
python -m jupyterlab notebooks/
```

## Rebuild

The notebooks are generated by `tools/build_notebooks.py`; edit that script, not
the `.ipynb` files. Then run `python tools/check_notebooks.py --write` to execute
every notebook and store its figures for static previews. Widget output is
replaced by a short note, because it cannot render without a kernel.

Exports from the playground go to `hetfront_exports/` beside the notebook.
